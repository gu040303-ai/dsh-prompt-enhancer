# 动效与状态提示修复安装包

[下载完整安装包 dsh-prompt-enhancer-0.4.0-motion-fix.tgz](https://github.com/gu040303-ai/dsh-prompt-enhancer/raw/refs/heads/motion-polish/downloads/dsh-prompt-enhancer-0.4.0-motion-fix.tgz)

此包包含可直接安装的编译产物、插件配置与资源，共 37 个文件、253,573 字节。它是基于 0.4.0 的修复构建，包内版本仍为 0.4.0，适配 DeepSeek Harness 0.2.1-rc.2。

## 安装

1. 下载 `.tgz`，无需解压。
2. 在 Harness 左侧「插件」中进入旧版插件详情并卸载。
3. 点击「添加插件」，在「包名或地址」填写下载文件的本地绝对路径。
4. 安装并启用，完整退出 Harness 后重新打开。

使用桌面原生管理器安装；不要通过 CLI 管理 desktop profile。

## 修复内容

- 移除持续呼吸光、正文模糊与逐行位移，改用轻微悬停反馈、短淡入与写回背景提示。
- 状态提示支持窄窗口换行，区分正在优化、生成预览、预览未写回、细节待确认及已写回。
- 失败和取消提示不再混入上次结果的操作；继续编辑会清理过时提示。
- 关闭提示保留侧栏结果；新结果会重新显示提示。
